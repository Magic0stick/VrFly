# 👥 Мультиплеер - Инструкция

## Как играть с друзьями

### 1. Создание комнаты

1. Откройте игру в браузере
2. Нажмите **"🎮 НАЧАТЬ ИГРУ"**
3. Появится лобби с кодом комнаты (6 символов)
4. Скопируйте код и отправьте друзьям

### 2. Присоединение к комнате

1. Откройте игру в браузере
2. Введите код комнаты в поле **"Присоединиться"**
3. Нажмите **"→"** или **"НАЧАТЬ ИГРУ"**
4. Вы подключитесь к комнате

### 3. Игра

- Все игроки видят друг друга в мире
- Можно сбрасывать десант (других игроков!)
- Синхронизация позиций в реальном времени
- Поддержка до ~10 игроков

## Технические детали

### Как это работает

- **PeerJS** - библиотека для WebRTC P2P соединений
- **Публичный signaling сервер** - PeerJS предоставляет бесплатный сервер для установки соединений
- **WebRTC** - прямое P2P соединение между игроками
- **Обновления каждые 50мс** - плавная синхронизация позиций

### Что синхронизируется

- ✅ Позиция и поворот самолёта
- ✅ Выстрелы из пулемёта
- ✅ Сброс десанта (другие игроки)
- ✅ Очки и здоровье
- ✅ Имена игроков

### Ограничения

- Максимум ~10 игроков (зависит от производительности)
- Требуется стабильное интернет-соединение
- Может быть задержка при плохом соединении
- Публичный сервер PeerJS может быть недоступен

### Решение проблем

**Не удаётся подключиться:**
- Проверьте интернет-соединение
- Убедитесь что код комнаты введён правильно
- Попробуйте создать новую комнату

**Лаги/задержки:**
- Проверьте скорость интернета
- Закройте другие приложения
- Уменьшите количество игроков

**Игроки не видны:**
- Убедитесь что все в одной комнате
- Проверьте что все нажали "НАЧАТЬ ИГРУ"
- Перезагрузите страницу

## Для разработчиков

### Структура сетевого взаимодействия

```typescript
// Отправка обновления позиции
multiplayer.sendPlayerUpdate({
  id: myId,
  position: { x, y, z },
  rotation: { x, y, z },
  health: 100,
  score: 0
});

// Отправка выстрела
multiplayer.sendBulletFire({
  position: { x, y, z },
  direction: { x, y, z },
  velocity: { x, y, z }
});

// Отправка десанта
multiplayer.sendDropTroop({
  position: { x, y, z },
  velocity: { x, y, z }
});
```

### Типы сообщений

- `playerJoin` - игрок присоединился
- `playerLeave` - игрок вышел
- `playerUpdate` - обновление позиции
- `bulletFire` - выстрел
- `dropTroop` - сброс десанта
- `hit` - попадание
- `chat` - сообщение в чат

### Настройка своего сервера

Для продакшена рекомендуется использовать свой signaling сервер:

```typescript
const peer = new Peer(myId, {
  host: 'your-server.com',
  port: 443,
  path: '/peerjs',
  secure: true
});
```

## Советы по игре

### Для пилота

- Держите самолёт ровно для точного сброса десанта
- Летите низко для лучшей точности пулемёта
- Избегайте дронов - они опасны!

### Для десанта

- Приземляйтесь в зону "H" для бонусных очков
- Координируйтесь с пилотом
- Будьте готовы к бою после приземления

### Командная игра

- Один игрок - пилот, другие - десант
- Чередуйтесь ролями
-Communicate через чат (в разработке)
