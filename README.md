# 🛩️ Sky Bug Hunter VR

Браузерная VR-игра для Meta Quest 2 и SteamVR с поддержкой управления самолётом, пулемётом, десантом и физическим взаимодействием с кабиной.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Откройте http://localhost:5173 в браузере.

## 🎮 Управление

### VR (Quest 2 / SteamVR)

**Левый контроллер:**
- Стик - руль и тангаж
- X/A - сброс десанта
- Trigger - взаимодействие с кнопками/рычагами

**Правый контроллер:**
- Стик - газ (вверх/вниз)
- Grip - пулемёт (удерживать)
- Y/B - ускорение
- Trigger - взаимодействие

### Десктоп (без VR)

- **W/S** - тангаж
- **A/D** - крен
- **Shift/Ctrl** - газ
- **Пробел** - пулемёт
- **E** - сброс десанта
- **Мышь** - обзор (клик для захвата)

## 🥽 Поддержка VR-систем

### SteamVR

**Поддерживаемые устройства:**
- Valve Index
- HTC Vive / Vive Pro / Vive Cosmos
- Windows Mixed Reality (HP Reverb G2, Samsung HMD)
- Pimax
- Bigscreen Beyond
- Meta Quest 2/3/Pro через ALVR или Virtual Desktop

**Как запустить:**
1. Запустите Steam и SteamVR
2. Подключите гарнитуру и контроллеры
3. Откройте игру в Chrome/Edge
4. Нажмите "🎮 STEAMVR"

### Meta Quest (нативно)

**Как запустить:**
1. Откройте Oculus Browser на Quest
2. Перейдите по ссылке на игру
3. Нажмите "🥽 OCULUS VR"

### Quest через SteamVR (ALVR)

1. Установите ALVR на ПК и Quest
2. Запустите SteamVR + ALVR сервер
3. Подключите Quest к ALVR
4. Откройте игру в SteamVR Browser

### Quest через Virtual Desktop

1. Установите Virtual Desktop
2. Запустите стрим на Quest
3. Откройте браузер в Virtual Desktop
4. Перейдите на страницу игры

## 🛠️ Разработка с VS Code

### Конфигурации запуска

В папке `.vscode/` находятся готовые конфигурации:

**launch.json** - конфигурации отладки:
- 🚀 Dev Server (Vite) - запуск dev-сервера
- 🌐 Chrome (Desktop Mode) - отладка в Chrome
- 🥽 Chrome + SteamVR Debug - отладка с WebXR флагами
- 🎮 SteamVR Browser Debug - подключение к SteamVR Browser
- 📦 Build Production - сборка для продакшена

**tasks.json** - задачи:
- `npm: dev` - запуск dev-сервера
- `npm: build` - сборка
- `npm: typecheck` - проверка TypeScript
- `Check SteamVR` - проверка SteamVR
- `Dev with HTTPS` - HTTPS режим (для WebXR)

### Рекомендуемые расширения

VS Code предложит установить рекомендуемые расширения при открытии проекта:
- ESLint - линтинг
- Prettier - форматирование
- Tailwind CSS IntelliSense
- ES7+ React/Redux snippets
- TypeScript Next
- GitLens
- и другие

### Горячие клавиши для разработки

- **F5** - запуск отладки (использует первую конфигурацию)
- **Ctrl+Shift+B** - запуск задачи сборки
- **Ctrl+Shift+D** - панель отладки
- **Ctrl+`** - терминал

### Отладка VR

1. Запустите dev-сервер: `F5` → "🚀 Dev Server (Vite)"
2. Откройте Chrome с WebXR: `F5` → "🥽 Chrome + SteamVR Debug"
3. Запустите SteamVR
4. В Chrome нажмите "Войти в VR"
5. Установите breakpoint в коде для отладки

## 🐛 Решение проблем

### VR не обнаружен

- Убедитесь, что SteamVR запущен
- Проверьте, что браузер поддерживает WebXR (Chrome/Edge)
- Для Quest: используйте Oculus Browser или ALVR/Virtual Desktop
- Проверьте, что гарнитура подключена и распознана

### SteamVR не работает

- Перезапустите SteamVR
- Проверьте, что контроллеры подключены
- Обновите драйверы SteamVR
- Попробуйте другой браузер (Chrome рекомендуется)

### Низкая производительность в VR

- Уменьшите разрешение рендеринга в SteamVR
- Закройте другие приложения
- Обновите драйверы видеокарты
- Для Quest: используйте Wi-Fi 5GHz или кабель

### Контроллеры не работают

- Перезапустите SteamVR
- Проверьте заряд контроллеров
- Перекалибруйте контроллеры в SteamVR
- Попробуйте другой USB-порт для базовой станции
